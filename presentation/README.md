# StreetBite presentation

[Open the presentation](StreetBite-project-final.pptx)

Seven slides cover the developer, planning, architecture, actual emulator screenshots and current verification status. Text remains editable. The deck uses StreetBite green (#00C874), white and Arial.

Validation completed: PPTX package integrity, slide geometry, heading fit, Arial font policy and first-party presentation import. Each rendered slide was visually reviewed, and incomplete image loading/fade-in captures were replaced. Native PowerPoint rendering has not been independently verified.

The final slide identifies remaining acceptance work. The deck is not a claim that the full capstone has passed final acceptance.

Sources and attribution are included in slide notes: the public StreetBite repository, Food Delivery Mobile App UI Kit by Vlad Solomakha (CC BY 4.0), TheMealDB and genuine emulator captures. Prices, vendor locations and payment results are demonstration data.
