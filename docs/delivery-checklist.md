# Delivery checklist

- [ ] Inspect every Figma frame after sign-in; record frame-to-screen mapping.
- [ ] Configure dedicated Firebase project and deploy tested rules.
- [ ] Enable Maps SDK and restrict Android/iOS keys.
- [ ] Implement and verify all functional requirements.
- [ ] `dart format .`, `flutter analyze`, `flutter test`.
- [ ] Test English/Arabic, light/dark, two screen sizes and restart/offline flows.
- [ ] Build signed beta APK; record checksum/version.
- [ ] Upload to Firebase App Distribution and invite two user-specified testers.
- [ ] Record actual real-device QA, Jira defects, traceability and closure.
- [ ] Execute Appium login, scrolling and cart scenarios on emulator and device.
- [ ] Capture genuine screenshots; never mark unexecuted checks as passed.
- [ ] Publish public GitHub repository and presentation.
